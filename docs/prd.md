## 1. 项目目标

把一份动辄两三百页、表格跨页、科目写法五花八门的 A 股财报，整理成**干净、能对比、每个数字都能回到原文核对**的财务视图。

核心价值：

1. **把「看不懂」变成「看得懂」**：三表结构化、20 项关键指标、10 组图表，回答「赚的钱是不是真的」这类问题。
2. **把「不敢信」变成「可核对」**：每个数字带页码与原文片段，点开即见出处。
3. **把「单期数字」变成「跨期趋势」**：多期对齐后自动算同比、环比，看结构变化而不是看孤立数字。

差异化不在「能解析」，而在**可核对 + 结构矛盾自动呈现**：通用 AI 给结论，本产品给有出处的证据。

## 2. 业务范围

### ✅ In Scope（做什么）

1. 上传与解析：A 股年报 / 半年报 PDF（文本型），自动定位三表并还原表格结构。
2. 结构化与归一：金额单位、正负号、空值、跨页表、合并单元格的统一处理。
3. 科目对齐：把原文科目名映射到标准 Schema；多期之间对齐同一指标。
4. 指标计算：20 项关键指标 + 同比 / 环比，全部由脚本计算。
5. 可视化看板：10 组固定图表（含异常项卡片），见 4.5。
6. 异常项呈现：只陈列数字之间的矛盾与背离，附原文页码，不做评价。
7. 溯源：每个数字可查看「页码 + 原文片段 + 计算口径」。
8. 导出：Markdown 报告与 Excel 明细。
9. 合规：常驻免责声明，输出不出现投资建议类表述。

### ❌ Out of Scope（不做什么）

1. 不做涨跌预测、目标价、估值打分、「是否值得买」类判断。
2. 不做荐股、组合建议、择时提醒。
3. 不自动抓取财报（巨潮 / 交易所 / 第三方源），只处理用户上传的文件。
4. 不做交易、下单、持仓管理、对账单。
5. 不支持港股、美股、新三板基础层、季报；不做多币种折算。
6. 不做扫描件 OCR（v1.1 再评估）；不做图片型 PDF 的承诺式解析。
7. 不做账号、订阅、付费额度（v1.1）。
8. 不做同业横向对比、不做研报生成、不做电话会纪要。

### 边界判定

- 输出只陈述「原文披露了什么」与「数字之间是否矛盾」，不陈述「所以好/坏/该买/该卖」。
- 缺失数据一律显式标注「原文未披露」，禁止补 0、禁止推测。
- 解析失败时给出可执行的失败原因（哪一页、哪张表、缺哪列），不输出猜测结果。

### 4.4 指标计算 metric

| 编号 | 功能 | 输入 | 输出 | 验收（布尔） |
| ---- | ---- | ---- | ---- | ---- |
| M1 | 20 项指标 | 结构化三表 | 指标值 + 口径 | 20 项全部可算出；不可算的项显示「原文未披露」并给出缺失原因 |
| M2 | 同比 / 环比 | 多期数据 | 增速数值 | 增速由脚本计算；基期为负或为零时给出「不适用」而非错误百分比 |
| M3 | 三表勾稽 | 三表数值 | 校验结论 | 资产 = 负债 + 权益强校验；不通过时页面顶部挂黄色提示条并列出差额 |
| M4 | 口径说明 | 指标定义 | 口径文本 | 每个指标可查看「取数科目 + 计算公式 + 单位」，且与实际计算逻辑一致 |

## 5. 非功能需求

### 5.1 质量门槛（硬指标，不达标不发布）

1. 三表数字与原文一致率 ≥ 99%（评估集每份抽 100 个数字人工核对）。
2. 20 项指标全部可算出且每条带溯源；缺失项显式标注，不允许填 0 或推测。
3. 三表勾稽强校验全部期次通过；不通过必须黄条提示并列出差额。
4. 投资建议类禁用词在页面与导出中零出现。

### 5.2 性能

- 单份 300 页年报：上传到首屏可读 ≤ 60 秒（P95），完整解析 ≤ 120 秒。
- 5 期会话首次对齐 ≤ 30 秒。
- 看板交互（切换、悬停、展开溯源）≤ 300ms。
- v1.0 并发：5 个解析任务并行，超出排队并显示排队位次。

### 5.3 可靠性

- 解析任务可重试；失败不产生半成品数据（要么完整入库，要么回滚）。
- 单份文件解析失败不影响同会话其他期次。
- LLM 不可用时降级：科目映射回退到规则表，未命中项标「待确认」，看板照常可看。
- 任务超时上限 10 分钟，超时给出明确提示与重试入口。

### 5.4 安全与隐私

- 上传原件仅在解析期间存在，解析完成即删除；不写长期存储、不用于训练。
- 结构化结果与溯源片段可一键清空。
- 日志不含财报全文与用户标识；仅记录页数、耗时、错误码、未对齐数量。
- 密钥仅从环境变量读取，禁止进代码库、禁止进前端。
- 传输 HTTPS；解析任务按会话隔离，不同会话不可互查。

### 5.5 可观测

- 每次解析输出运行摘要：页数、三表定位页、解析耗时、未对齐科目数、LLM 调用次数与失败次数、勾稽校验结论。
- 关键指标打点：解析成功率、首屏时长、溯源点击率、导出次数。
- 解析成功率低于 90% 时告警。

### 5.6 合规

- 全站与导出文件常驻免责声明：仅做信息提取整理，不构成投资建议，数据请自行核验。
- 禁用词表机器校验，结果进入发布门槛（见 5.1）。
- 不承诺 100% 正确：页面明确「会计估计与附注调整可能导致口径差异，以公司披露原文为准」。

### 5.7 兼容与可用性

- 浏览器：Chrome / Edge 最近两个大版本；桌面优先，移动端只保证可查看。
- 首次使用三步内出结果：上传 → 解析 → 看板；中途失败必须给出「哪一步、哪份文件、哪一页」。
- 文案全中文；专业术语首次出现时给一句话解释（如「扣非净利润」）。

### 5.8 数据规模假设

- 单份 ≤ 400 页 / ≤ 50MB；单会话 ≤ 5 期；单期三表科目行数 ≤ 120 行。

### A.2 金标标注

- 每份标注：三表各 30 个数字（含至少 5 个跨页 / 合并单元格数字）+ 20 项指标期望值 + 关键数字页码。
- 标注由人工完成，结果随代码入库（`tests/eval/`）并版本化。

### A.3 评分与通过条件

| 指标 | 计算方式 | v1.0 门槛 |
| ---- | ---- | ---- |
| 三表定位 | 正确份数 ÷ 10 | 10/10 |
| 数字一致率 | 与金标完全一致的数字数 ÷ 抽样总数 | ≥ 99% |
| 科目映射准确率 | 正确映射科目数 ÷ 应映射科目数 | ≥ 95% |
| 指标可算出率 | 可算出并有溯源的指标数 ÷ 20 | 20/20（缺失项需显式标注） |
| 溯源页码正确率 | 正确页码数 ÷ 抽样溯源数 | ≥ 98% |
| 禁用词 | 全文匹配次数 | 0 |
| 首屏时延 | P95 | ≤ 60 秒 |

- 评测失败不进入 done；修复后重跑全量并留存报告。
