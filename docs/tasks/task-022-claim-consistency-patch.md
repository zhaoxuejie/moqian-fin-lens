## 背景与目标

README 的第一句承诺是「每个数字都能回到原文页码」，PRD 定了「异常项无页码不展示」「只描述数值关系」。v0.4.0 有 5 处与这些承诺不一致，另有 README 测试徽章与新克隆仓库的实测不符。本卡只修这些，让对外说法与代码行为一致，发布 v0.4.1；不新增功能，v1.1 范围内的事项不在本卡处理。

## 执行步骤

1. **异常项带页码**：取数时为每个标准科目记录「首次精确命中行」的页码；每条异常规则把证据科目的页码写进 `page_refs`；勾稽不通过项取参与勾稽的科目页码。`page_refs` 为空的异常项不返回（与接口契约「`page_refs` 至少一个，否则不返回该项」一致）。
2. **ROE 口径名实一致**：指标名由「加权平均净资产收益率」改为「净资产收益率（ROE）」，公式改为「归母净利润 ÷ 平均归属于母公司所有者权益 × 100」；归母权益未取到时显示「原文未披露」，不静默退回所有者权益合计。同步图表 ④ 口径说明与 PRD V4。指标 `code` 仍为 `roe`，接口不变。
3. **异常规则补齐 8 条**：异常项输入是单期年报的「本期 + 上期比较列」（PRD 4.6），只有两个点，「连续下滑」无法判定。PRD R1 两条改为「经营现金流同比下降」「毛利率同比下降」；新增 `gross_margin_declining`（本期毛利率比上期低 ≥ 1 个百分点）。
4. **概览摘要**：应收增速一行引用了不存在的指标 `accounts_receivable_growth`，永远不出现。改为由三表取数直接计算；该行与现金含量一行的措辞改为只陈述数值与比较关系（去掉「关注回款质量」「基本有现金支撑」「偏低」）。
5. **公司与期次从正文识别**：从前 10 页文本识别证券代码、证券简称、报告年度与报告类型（年度 / 半年度），优先于文件名；正文识别不到才回退文件名。识别为半年度报告时显式拒绝（新错误码，提示「暂不支持半年报」），不再按年报口径静默解析。追加上传时，同一公司优先按证券代码判断。
6. **README 测试说明**：徽章「238 项 / 90.55%」是放入评估集 PDF 后的结果；新克隆仓库没有 PDF 时 16 项真实年报用例跳过（222 通过、覆盖率 82%）。README 写明两种口径与评估集获取方式。

## 验收标准（布尔判定）

1. 评估集 10 份年报：接口返回的每条异常项 `page_refs` 至少 1 个，且页码就是证据科目在单年报表里的溯源页码。
2. 代码、页面、导出中不再出现「加权平均净资产收益率」；ROE 公式文本与计算逻辑一致（单测断言）。
3. 异常规则 8 条，每条至少 1 个命中用例与 1 个未命中用例；PRD R1 文字与规则清单一一对应。
4. 构造「应收增速高于营收 10 个百分点以上」的数据，概览摘要出现应收增速一行；摘要全部文案通过禁用词校验，且不含「关注」「偏低」「支撑」等评价词。
5. 评估集 10 份年报改名为「年报.pdf」后上传：公司简称、证券代码、报告年度全部识别正确；构造半年报样本返回新错误码且不产生会话。
6. README 写明有 / 无评估集两种测试口径，数字与实测一致。
7. 回归：全量 pytest 通过、覆盖率 ≥ 80%；表格评测仍为 96.0%，指标可比样本一致率不低于 95.88%。

## 评测方案

- 单测：异常规则命中 / 未命中、页码填充与空页码过滤、ROE 公式、摘要措辞、正文识别（代码 / 简称 / 年度 / 半年报）。
- 真实年报：评估集 10 份（`tests/eval/pdf/` 本地放置，不入库）跑 `run_table_eval.py`、`run_metrics_eval.py`，并逐份核对异常项页码与正文识别结果。
- 回归：全量 pytest + 覆盖率门槛。

## 风险与备注

- ROE 改为归母口径后，若某份年报的「归属于母公司所有者权益合计」没有取到，该期 ROE 会从有值变为「原文未披露」；评测时统计 10 份里可算出的份数，写进评测结果。
- 指标金标中 ROE 10 条均为金标侧缺失，本次口径修改不影响一致率统计。
- 不在本卡范围：LLM 科目兜底、扫描件识别、半年报解析、坐标级溯源、多科目指标的完整溯源、会话持久化改为结构化表、任务重启恢复（均留 v1.1）。
