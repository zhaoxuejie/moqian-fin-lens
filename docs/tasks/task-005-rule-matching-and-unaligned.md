## 背景与目标

把原文科目名映射到标准科目，并且**在映射不了的时候明确说出来**。本卡只做单期、规则与模糊匹配；LLM 候选与多期对齐属于后续任务卡。

## 执行步骤

1. 实现 `align.map_account(row, schema, aliases)`：精确别名 → 归一化匹配（去空格、全半角归一、去「其中：」「减：」「加：」前缀）→ 相似度匹配。
2. 输出 `{account_code, confidence, source}`，`source` 取 `rule` / `fuzzy`。
3. 未命中或低于阈值时写入未对齐清单（原文科目名 + 页码 + 相似度），不进入三表。
4. 置信度阈值可配置，默认值写进 `.env.example`。
5. 保证一个原文科目最多映射到一个标准科目；同一标准科目可承接多个原文写法。
6. 输出未对齐计数，供 `GET /api/v1/sessions/{id}` 的 `unaligned_count` 使用。

## 交付物

- `align/map_account` 实现
- 未对齐清单数据结构与计数
- 阈值配置项
- 评估集映射准确率脚本

## 验收标准（布尔判定）

1. 评估集科目映射准确率 ≥ 95%（正确映射数 ÷ 应映射数）。
2. 未命中项 100% 出现在未对齐清单，且每项含原文科目名与页码。
3. 构造「乱码科目名」样本：不静默丢弃、不进入三表、不参与任何指标计算，只在未对齐清单出现。
4. 不存在一个原文科目被映射到两个不同标准科目（脚本断言）。
5. 置信度低于阈值时，`source` 为 `fuzzy` 且进入「待确认」，不直接当作正确映射。
6. 调整阈值只改配置，不改代码；配置生效可验证。

## 评测方案

- 准确率脚本：评估集 → 映射结果 → 与金标科目比对 → 输出混淆矩阵与准确率。
- 负样本：乱码科目、无意义符号、跨表同名干扰，各 3 例，验证全部进入未对齐。
- 人工抽检：随机 20 条映射，核对 `account_code` 与原文语义一致。

## 风险与备注

- 相似度匹配容易「看似合理」的误配（如把「其他收益」匹配到「营业外收入」），因此本卡要求误配必须进入待确认而不是静默通过。
- 中文科目名相似度高，阈值定得过低会提升覆盖率但拉低准确率；以评估集准确率 95% 为唯一标准，不接受用覆盖率换准确率。

## 评测结果（2026-10-31）

| 项 | 结果 |
| ---- | ---- |
| 对齐准确率 | 100/100（真实标签 60 + 变体 25 + 负样本 15），误配 0 条 |
| 未对齐显式化 | 未命中项 100% 返回 unaligned，且带页码与原科目名，不再静默丢弃 |
| 乱码 / 表头 | ＃＠乱码科目、合并利润表、分组标题均不进入三表，reason 区分 no_match / section_header / statement_mismatch |
| 一致性 | 同一原文标签多次调用恒返回同一 account_code |

| 测试 | 139 项通过，覆盖率 97.46% |
