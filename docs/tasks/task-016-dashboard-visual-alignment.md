## 背景与目标

看板页当前是功能骨架：没有顶栏导航与期间条，KPI 只有公式没有同比箭头，图表卡缺副标题，异常项是无编号的纯文本。原型已经确认过视觉方向，本卡按原型逐区块对齐，不改任何数据与接口。

## 执行步骤

1. 顶栏：品牌 + 锚点导航（概览 / 三表 / 图表 / 异常）+ 导出按钮。
2. 上传 / 期间条：期次 chips（可点击切换）+ 虚线「继续上传」区域，替代当前小按钮。
3. KPI：数值 + 同比箭头（▲/▼ + 百分比或百分点）+ 溯源按钮；无同比时回退到口径说明。
4. 三表：保持 Tab 与溯源 chips，补表头单位与行悬停。
5. 图表卡：标题 + 副标题（口径）+ 图 + 缺失提示，间距与原型一致。
6. 异常项：编号图标 + 标题 + 说明 + 证据 / 页码 chips。
7. 页脚免责声明样式对齐原型。
8. 用原型截图与实现截图并排走查。

## 验收标准（布尔判定）

1. 页面包含顶栏导航、期间条、KPI 同比、图表副标题、异常编号卡、免责声明六个区块。
2. 期间 chips 可点击且切换后三表与 KPI 对应期次变化。
3. KPI 有同比时显示箭头与数值；无同比时显示口径文本。
4. 页面功能不回归：既有 219 项测试通过，页面结构测试通过。
5. 人工走查：原型与实现的区块顺序、栅格列数、卡片样式一致。

## 补充修复（2026-11-01 试用反馈）

- 顶栏错位：.topbar 改为块级，.topbar-inner 承担 flex，品牌左对齐、导出右对齐；
- 继续上传报「不是同一公司」：company_key 补充剥离代码前缀与「年年度报告」后缀，新旧会话名可正确归一；

- 公司名：上传时清洗为「科大讯飞」等简称。

## 图表编号与单位（2026-11-01 试用反馈）

- 图表标题改为圈号：① 利润的含金量 … ⑦ 现金流从哪来、到哪去，与原型一致；
- 金额轴按单位自动换算：≥1 亿显示「xx 亿」，≥1 万显示「xx 万」；双轴图左轴金额、右轴倍数分别格式化；
- 副标题补充「单位：亿元 / 倍 / %」；tooltip 数值同步格式化。
