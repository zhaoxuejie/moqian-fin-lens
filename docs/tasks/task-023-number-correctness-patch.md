# TASK-023 数值正确性修补（PATCH）

- 编号：TASK-023
- 里程碑：v1.0（数据质量）
- 前置依赖：TASK-022
- 优先级：P0
- 状态：✅ done（2026-11-04 验收通过）
- 来源：v0.4.1 在评估集 10 份年报上逐份复跑指标时发现 4 个数值层面的问题（写作系列文章时对照代码自查）
- 关联文档：`docs/prd.md` 4.2 P3、4.4 M1、5.1；`docs/tasks/task-003-number-normalization.md`；`docs/tasks/task-014-metric-extraction-gaps.md`

## 背景与目标

v0.4.1 有 4 处会让页面上的数字错误或缺失：

| # | 问题 | 评估集上的影响 |
| ---- | ---- | ---- |
| 1 | 报表表头「单位：千元」没有读，表格还原一律按元归一 | 中芯国际 2 份年报全部绝对金额小 1000 倍（2024 营业收入存成 57,795,570 元，应为 57,795,570,000 元） |
| 2 | 上交所写法「所有者权益（或股东权益）合计」「1.归属于母公司股东的净利润（净亏损以"-"号填列）」匹配不上 | 金山办公、中芯国际 4 份年报：ROE 算不出，两条勾稽跳过，归母净利润显示「原文未披露」（原文有） |
| 3 | 利润表不列「营业总收入」时，依赖它的指标与图表全部缺失 | 海康威视 2 份年报：毛利率、净利率、应收周转天数、三费占比、营收增速缺失，只算出 13/20 项 |
| 4 | 有息负债要求短期借款、长期借款、应付债券三项全在 | 7/10 份年报因没有「应付债券」显示「原文未披露」；图表层的同一指标却按「至少一项」计算，两处口径不一致 |

本卡只修这 4 处，并同步修正受影响的金标，发布 v0.4.2。不改指标清单、不改接口。

## 执行步骤

1. **读表头单位**：按三张表各自的页范围，从页面文本里读出「单位：元 / 千元 / 万元 / 百万元 / 亿元」（允许「人民币」前缀），作为 `unit_hint` 传给表格还原、坐标聚类兜底与首行回填；扣非净利润兜底按它所在页读单位。读不到时按元。单年报表仍显示原文字符串（`cell.raw`），不受影响。
2. **上交所写法**：科目 Schema 补 3 个别名（「所有者权益（或股东权益）合计」「归属于母公司所有者权益（或股东权益）合计」「负债和所有者权益（或股东权益）总计」），版本 1.0.5 → 1.0.6；科目名归一时去掉开头的阿拉伯数字编号（「1.」「2、」）和结尾的「（……填列）」说明。
3. **营业总收入缺省**：毛利率、净利率、应收周转天数、三费占比、营收增速在「营业总收入」未列示时改用「营业收入」，口径文本写明；图表层同一组计算同样回退。「营业总收入」这一项本身在未列示时仍显示「原文未披露」，不把营业收入冒充成营业总收入。
4. **有息负债**：至少有一项借款科目就计算，缺的项不计入；全部缺失才「原文未披露」。同比改为按有息负债合计计算（原来取的是第一个依赖科目短期借款的同比）。
5. **金标**：`build_table_gold.py`、`build_metrics_gold.py` 同样读表头单位；用修复后的代码重新生成 `table-200.json`、`metrics-200.json`，逐条列出变化并归因（单位 / 写法 / 回退 / 有息负债）。生成前已确认：用 v0.4.1 代码重新生成，两份金标与入库版本逐字节一致，因此变化全部来自本卡。
6. **扣非净利润兜底（评测中发现，追加）**：复跑中芯国际时，扣非净利润 2024 读成 -19,110 元、2025 读成一个 19 位数。原因是兜底先把页面文本的空白全部去掉再找金额：千元报表的金额是不带小数的整数，「2,645,419 3,269,518 -19.1 10,133,988」去掉空白后粘成一串，只能靠小数点断开。v0.4.1 同样读错（-19.11 元），TASK-014 的「扣非 10/10 可提取」包含了这两个错误值。修法：保留空白作分隔，科目名允许折行，后面紧跟两个金额才采用（跳过叙述性提及），科目名后的「（元）」「（千元）」作为单位。

- 重新生成的两份金标与变化归因
- CHANGELOG `[0.4.2]`、PRD 4.4 口径说明（营业总收入回退、有息负债）

## 验收标准（布尔判定）

1. 10 份年报的表头单位识别为：中芯国际 2 份千元，其余 8 份元；中芯国际 2024 营业收入 = 57,795,570,000 元；单年报表页显示的仍是原文字符串。
2. 金山办公、中芯国际 4 份年报：所有者权益合计、归母权益、归母净利润都能取到；ROE 10/10 可算出；「资产 = 负债 + 权益」「净利润 = 归母 + 少数」两条勾稽 10 份都不再跳过。
3. 海康威视 2 份年报：毛利率、净利率、应收周转天数、三费占比、营收增速有值且口径写明回退；「营业总收入」一项仍为「原文未披露」。
4. 有息负债：至少一项借款科目有值即可算出；同一期的指标值与图表「资产结构」里的有息负债一致。
5. 评测：三表定位 30/30、数值归一 100/100、科目对齐 100/100、异常项页码全部一致；表格还原不低于 96.0%；指标与金标的不一致只允许出现在已归因的变化里。
6. 中芯国际 2024 / 2025 扣非净利润为 2,645,419,000 / 4,124,287,000 元（原文千元）；其余 8 份年报的扣非净利润与 v0.4.1 逐分一致。
7. 全量 pytest 通过、覆盖率 ≥ 80%（含评估集 PDF）。

## 评测方案

- 单测：表头单位识别（各单位写法、读不到默认元）、科目名归一（编号、填列说明）、营业总收入回退、有息负债至少一项、有息负债同比。
- 真实年报：10 份逐份打印单位、20 项指标覆盖数、勾稽状态；与 v0.4.1 逐项对比。
- 金标：重新生成后输出逐条差异与归因，写入本卡评测结果；评测脚本输出保存为文件随提交入库（`tests/eval/reports/`），本卡验收记录引用文件，不手抄数字。

## 风险与备注

- 科目名去掉结尾「（……填列）」后，「（一）持续经营净利润（……填列）」会变成「持续经营净利润」，仍可能被后缀匹配挂到净利润；靠「取首次出现」保护，本卡不扩大处理范围，记入已知问题。
- 营业总收入回退只适用于未列示该行的报表；同时列示两行时仍取营业总收入。
- 不在本卡范围：利息收入列归属、两套科目匹配合一、未对齐清单上页面、CI 中的真实年报、指标溯源列出全部依赖科目。
