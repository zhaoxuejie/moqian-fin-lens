## 背景与目标

部分年报的报表首行会被 pdfplumber 并进表头（如第 114 页审计报告与资产负债表交界），导致「货币资金」等首行缺失，进而影响指标（货币资金、现金含量）与溯源页码。本卡做按页文本的精确回填。

## 执行步骤

1. 定位缺失：某张表若在起始页 ±1 页内没有首行锚点科目（资产负债表：货币资金；利润表：营业总收入/营业收入；现金流量表：销售商品），判定为首行丢失。
2. 从该表起始页文本中按行匹配「锚点科目 + 两个金额」，取第一个匹配。
3. 构造 StatementRow 插入对应报表的**最前面**，页码取该行所在页，片段取该行文本。
4. 校验金额：回填值需与页面文本一致，且正负号保留。
5. 回归指标：货币资金、现金含量等指标随回填更新。

## 交付物

- 首行回填逻辑（session 构建阶段）
- 单测与真实年报验证
- 溯源页码与浮层整页文本一致

## 验收标准（布尔判定）

1. 科大讯飞 2024 资产负债表第一行为「货币资金」，页码为 PDF 实际页（114）。
2. 回填金额与原文一致（本期 3,387,380,425.36、上期 3,562,635,256.73）。
3. 资产负债表总计仍平衡（资产总计 = 负债 + 权益）。
4. 其他报表与指标不回归：全量测试通过。
5. 溯源点击首行时，浮层页码与整页文本包含该行。

## 评测方案

- 真实年报：科大讯飞 2024，断言首行、金额、页码。
- 回归：全量 pytest；对比台/导出数据复查。

## 风险与备注

- 只回填「整行缺失」的情况，不做逐行 OCR 对齐；
- 若页面文本本身缺该行，保持缺失并记录日志。
