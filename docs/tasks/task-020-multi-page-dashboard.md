## 背景与目标

单页把「单年原始报表」与「跨年对比」混在一起，页面长、维度不清、无法深链。本卡拆为四个页面，并用贯穿全站的「公司上下文条」保持上下文。

## 路由

| 页面 | 路由 | 内容 |
| ---- | ---- | ---- |
| 概览 | `/s/{id}` | 结论摘要、关键指标、异常摘要、数据质量 |
| 单年报表 | `/s/{id}/statements?period=YYYY` | 该年原始三表（本期/上期）+ 溯源 |
| 跨年对比 | `/s/{id}/compare` | 历年对比（值与同比） |
| 图表与异常 | `/s/{id}/charts` | 7 组图表 + 异常明细 |

## 执行步骤

1. 公共布局：品牌、页面导航（概览 / 单年报表 / 跨年对比 / 图表异常）、公司上下文条（公司、代码、期次 chips、导出图标）。
2. 概览页：规则化结论摘要（3～5 条）+ 8 项关键指标 + 异常摘要条 + 数据质量条。
3. 单年报表页：期次切换 + 原始三表 + 溯源弹层。
4. 对比页：对比工具栏（报表 Tab、单位切换、增减额开关）+ 对比表。
5. 图表页：7 组图表 + 异常项明细。
6. 前端脚本按页面元素存在性降级，单份 JS 复用；溯源接口带期次。
7. 旧链接兼容：原 `/s/{id}#tables` 等锚点重定向到对应页面（301/302）。
