## 背景与目标

详情页把「公司档案（不变）」「本期报告（随解析变）」和期间导航混在一张卡片里；对比台金额为长串原始数字，无法一眼识别量级。本卡做信息分层与对比台读优化。

## 执行步骤

1. 拆成两张卡：
   - 公司档案：简称、代码、交易所、公司全称、注册地址、办公地址；
   - 本期报告条：期间切换 chips、继续上传、报告期、页数、勾稽、解析时间。
2. 对比台单位：
   - 默认自适应（≥1 亿显示亿，≥1 万显示万，其余原值）；
   - 单位切换：自适应 / 元 / 万元 / 亿元，选择存 localStorage；
   - 悬停展示原始完整值（title）。
3. 对比台增加「增减额」列：每年（除基准年）显示相对上一年差额，按当前单位格式化。
4. 回归：原有三表、图表、异常、导出不变。

## 交付物

- 详情页模板与样式调整
- 对比台单位切换与增减额
- 对比接口补充 delta 字段
- 测试与截图

## 验收标准（布尔判定）

1. 公司档案卡不含报告期 / 页数 / 解析时间。
2. 本期报告条含期间 chips、继续上传、报告期、页数、勾稽、解析时间。
3. 对比台默认自适应单位，列头标注「单位：自适应」。
4. 切换元 / 万元 / 亿元后数字按对应单位重算。
5. 鼠标悬停单元格显示原始数字。
6. 多期时显示增减额列，单期时不显示。
7. 单位选择在刷新后保持（localStorage）。
8. 全量测试通过。

## 评测方案

- 接口测试：compare 返回 delta 字段。
- 页面结构测试：包含「公司档案」「本期报告」「增减额」。
- 人工走查截图：不同单位切换、悬停原文。

## 风险与备注

- 单位切换只影响对比台展示，不改原始数表与存储。
- 多期（>2）时增减额按列展开，表格变宽，靠横向滚动承载。

## 补充（2026-11-01 二轮）

- 公司档案新增：外文名称、外文名称缩写、法定代表人、公司网址、电子邮箱（从年报前 20 页抽取）；
- 字段顺序：简称 / 代码 / 交易所 / 法定代表人 → 中文全称 / 外文名称 / 外文缩写 → 网址 / 邮箱 → 注册地址 / 办公地址；

- 展开状态写入 localStorage（company_detail_open），刷新保持；
- 公司档案不再占用首屏高度，KPI 上移。
