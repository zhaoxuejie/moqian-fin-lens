## 背景与目标

原型方向作废，按实际使用反馈重构：主色改红系（股市忌绿）、首页上传体验升级、详情页增加基本信息栏、三大报表回归「原始解析数」、新增跨年对比台（动态加工）。

## 执行步骤

1. 品牌色：主色由绿改红系渐变（柔和、不刺眼）；下跌/下降仍用绿色。
2. 首页：
   - 顶栏品牌贴内容区左缘；
   - 上传区改为大号拖拽区，拖入即显示文件名、大小、份数；
   - 主按钮加大加亮；
   - 解析过程加进度条与阶段提示，等待不再只有一行百分比。
3. 详情页：
   - 年报导航上方增加「基本信息」栏（公司、代码、报告期、页数、勾稽、解析时间）；
   - 三大报表只展示原始解析数字（保留 PDF 原始单位与千分位，不做亿元换算），供与原文比对；
   - 新增「跨年对比台」：三大报表按年列展示科目数据，逐年给出同比 %（相对上一年），顺序为资产负债表、利润表、现金流量表。
4. 新增对比接口：`GET /api/v1/sessions/{id}/compare`，按报表返回期间列、科目行、数值与同比。
5. 回归：原有看板指标与图表不变，测试全绿。

## 交付物

- 品牌色与首页交互
- 基本信息栏
- 原始数三表
- 跨年对比台（接口 + 页面）
- 测试与截图

## 验收标准（布尔判定）

1. 首页与详情页主色为红系渐变，下降箭头仍为绿色。
2. 首页拖入 2 个文件后立即显示文件名与份数；按钮为醒目主色。
3. 解析过程中展示进度条与阶段文案（解析表 / 对齐科目 / 计算指标）。
4. 详情页基本信息栏位于年报导航上方，含公司、代码、报告期、页数、勾稽。
5. 三大报表显示原始数字（含千分位与原始单位），不做亿元换算。
6. 跨年对比台可按资产负债表 / 利润表 / 现金流量表切换；每年一列，同比显示相对上一年。
7. 对比接口返回结构符合契约，单期会话时同比列为空。
8. 全量测试通过（覆盖率门槛 80%）。

## 评测方案

- 接口测试：compare 返回期间列、科目行、同比。
- 页面结构测试：基本信息栏、原始数表格、对比台存在。
- 人工走查截图：首页上传态、进度态、详情页三块。

## 风险与备注

## 二次反馈修订（2026-11-01）

- 基本信息栏扩展：简称、股票代码、交易所（按代码前缀推导）、公司全称、注册地址、办公地址（从年报前 20 页抽取）；
- 三大报表顺序改为资产负债表 → 利润表 → 现金流量表；
- 跨年对比台：表内字色加深（#111827）、斑马纹与悬停；容器固定 560px 内部滚动，切换 Tab 不再引起页面跳动；
- 结论：对比台保留「合并 Tab + 固定高度」，不拆成三段（避免页面过长与三表区重复）。

## 三次反馈修订（2026-11-01）

- 修复：对比台部分行显示的是科目代码（revenue_total / cost_total），现在回退到 Schema 的中文科目名；
- 对比台固定 560px 高度、表内滚动已生效。
