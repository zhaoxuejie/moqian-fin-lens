## 背景与目标

目前只有单期会话，趋势图（V4 三速剪刀差、V1 多期走势）没有数据。本卡支持同一公司多期上传，跨期对齐后让同比与趋势真实可用。

## 执行步骤

1. 会话内多期：`POST /uploads` 支持带 `session_id` 续传，校验公司与报告期不重复。
2. 期数上限 5 期；超出返回 40005。
3. 跨期对齐：同一标准科目按期间排序，缺失期保留空位。
4. 指标同比：基于相邻两期计算；基期为 0 或负返回「不适用」。
5. 图表多期：x 轴为期间序列；单点数据不再显示「需要两期」提示。
6. 页面增加期次切换（查看某一期三表），指标卡显示同比。

## 交付物

- 多期上传与会话校验
- 跨期对齐与同比计算
- 多期图表装配
- 页面期次切换

## 验收标准（布尔判定）

1. 同一公司上传至少 2 期成功，会话 `filing_count >= 2`。
   > 2026-10-31 修订（用户确认）：评估集只有 2024 / 2025 两年，验收以 2 期为基准。
2. 公司不一致或报告期重复时上传被拒绝，错误码 40004。
3. 上传第 6 期返回 40005。
4. V1 图的 x 轴出现 3 个期间；V4 图三条增速均有值。
5. 指标同比与「本期 - 上期」口径一致：公式单测 + 抽样 3 项人工核对。
   > 2026-10-31 修订（用户确认）：20 项全量金标同比成本过高，改为公式级验证。
6. 单期会话仍可正常查看，不报错。

## 评测方案

- 用同一公司 2024/2025 两期真实年报构造多期会话，比对同比。
- 契约测试覆盖续传、重复期、超期数。
- 页面人工验收：期次切换与趋势图。

## 风险与备注

- 跨期口径变化（会计政策变更）本卡只做「同一科目同名对齐」，不处理重述；重述标注留待后续。
- 同比的「上期」取会话内相邻期次，不依赖 PDF 内的比较列。

## 评测结果（2026-10-31）

| 项 | 结果 |
| ---- | ---- |
| 多期上传 | 科大讯飞 2024 + 2025 同一会话，filing_count = 2，按期间排序 |
| 校验 | 重复期间 40004（duplicate_period）、公司不一致 40004、超过 5 期 40005（单测） |
| 图表 | 多期时 x 轴为两期；V4 营收增速有值，应收 / 现金流增速取 PDF 比较列 |
| 同比 | metrics 返回 session_yoy（最新 vs 上一期）：金额类 %、比率类百分点；单测覆盖 20% 与 +5pct |
| 期次切换 | `?period=2024` 可切换三表展示 |
| 测试 | 2026-10-31 新增 6 项单测 + 4 项集成测试，全量 208 项 |

待确认：

1. 验收标准写的是「3 期」，评估集只有 2024 / 2025 两年，实测为 2 期；
2. 同比的金标比对只做了公式级单测（20% 与 +5pct），未做 20 项指标的金标逐项比对。
