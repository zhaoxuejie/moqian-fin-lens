## 背景与目标

溯源是本产品的差异化，也是「可核对」的落点；导出是财经创作者的出口。本卡把两者做完整：任何数字都能查到出处，导出的内容与页面完全一致且带免责声明。

## 执行步骤

1. 溯源查询服务：`GET /trace/{entry_id}` 返回页码、原文片段、单位换算说明、计算口径；数据来自 TASK-006 的单元格记录。
2. 溯源弹层接线：指标卡、三表行、图表数据点均可打开。
3. 无出处拦截：入库与渲染两处校验，缺页码的数据不得出现（对应 PRD T3）。
4. Markdown 导出：基础信息、三表、20 项指标、8 图说明、异常项、页码引用、免责声明。
5. Excel 导出：三表明细 + 指标表，数值型单元格。
6. 导出与页面一致性：同一会话导出内容与页面展示逐项比对。
7. 禁用词扫描：导出文本过词表，命中即失败。

## 交付物

- `trace/service.py` 与接口实现
- `export/markdown.py`、`export/xlsx.py` 与接口实现
- 导出记录与下载链接（1 小时有效）
- 评测脚本：溯源抽样、导出一致性、禁用词

## 验收标准（布尔判定）

1. 抽样 100 条数据（三表 + 指标），溯源页码正确率 ≥ 98%。
2. 无页码的数据不会出现在页面与导出中（构造脏数据验证）。
3. Markdown 导出含七个规定区块，且顶部有免责声明。
4. Excel 导出含三表明细与指标表，数字为数值型（打开后可直接求和）。
5. 同一会话的页面值与导出值逐项一致（脚本比对）。
6. 导出文本禁用词命中 0 次。
7. 导出生成耗时 ≤ 5 秒，下载链接 1 小时后失效。

## 评测方案

- 溯源抽样：金标页码 vs 实际返回，输出正确率。
- 导出一致性：解析 md / xlsx，与接口数据逐项比对。
- 禁用词：正则词表扫描，命中即打印上下文。
- 脏数据：手工构造缺页码记录，验证被拦截。

## 风险与备注

- 溯源依赖 TASK-006 的单元格坐标；若 006 未交付 bbox，先落页码 + 片段，不阻塞本卡。
- Excel 的「数值型」容易被写成字符串，评测必须读取单元格类型而不是只看文本。
